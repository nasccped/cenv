# cenv

An environment runner built on C.

## About

This program is just an environment runner built on top of C. Tools like these already exists.
I've just made it for fun!

## Requirements

This project can be only build with the following tools:

- `C` compiler / lib compatible
- `git` program _(metadata is used within source compile)_
- `make` program

## Set up

1. Clone the repository:
```sh
git clone https://github.com/nasccped/cenv && cd  cenv
```
2. Build it with `make`:
```sh
make build
```
